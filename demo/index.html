识别方法：以本站逐日海温（2022-11-23 起 1412 天）建 31 天滑动季节气候态，按 Hobday et al. (2016) 定义（异常超过本站记录期 p90 = 0.3908 °C 且持续 5 天以上）判定海洋热浪，再按 Hobday et al. (2018) 用峰值异常分级。分档阈值全部取本站自身记录的分位数（p50 = 10.586 / p75 = 15.611 / p90 = 17.872 C 天），不引用任何外部阈值。
官方交叉验证：本站月累计热异常 vs NOAA CRW 太平洋月最大占比（45 个完整月）r = 0.303；年尺度 r = 0.838（3 个完整年），全部 4 年排序 Spearman rho = 1.000 —— 站内累计热异常排序与官方太平洋年最大占比排序完全一致，2024 年双方都是峰值年。反过来，逐日热压力日数与官方区域占比只有 r = -0.031，区域级产品无法替代本站逐日判断，这正是本站识别的价值。按 NOAA 口径的 DHW 在本海温产品上恒为 0（白化阈值 31.52 °C 高于全期最高海温 31.45 °C），因此本卡用累计热异常而不是 DHW 作为本地识别量。
事件级对照（1421 天重叠）：站内 13 次热浪里 3 次同期官方太平洋占比也越过其 p90 = 0.08739（命中率 23.1%），官方峰值平均滞后 4.2 天；站内热浪日有 13.5% 落在官方抬升日，官方抬升日里站内也报 9.1%（背景抬升率 10.1%，提升 1.35 倍）。官方占比是整个太平洋的面积比例，本站事件大多是局地的：这既解释了为什么年尺度排序能对上（rho = 1.000）而事件级对不上，也说明本地识别不能被区域级产品替代。
区域站点对照（同一片沙巴海域的官方 5 km 产品，比流域占比更近一层）：NOAA CRW「Sabah, Malaysia」区域虚拟站点与本站重叠 1409 天，站内 13 次热浪有 13 次落在官方预警期内（100.0%）；本站日均海温与官方热斑像素 SST 平均只差 -0.013 °C（r = 0.717）。官方站点最新（2026-10-14）DHW = 14.01、预警级别 4（4 = Alert Level 2，最高档），而本项目自算 DHW 为 0 —— 差别来自基线：官方长期 MMM = 29.4999 °C，本项目短记录暖月均 = 30.517 °C。官方站点在重叠期内有 1160 天（82.3%）处于预警状态，所以它能印证「这段时期确实热」，但不能当作逐日触发线——逐日触发仍看本页阈值。

本页的诚实清单（哪些地方模型不行）

  • 四个时效的 RMSE 都低于常数均值（永远预报平均值），但 3 / 7 / 14 天只赢 0.0035 / 0.0011 / 0.0024，仍是噪声量级；只有 1 天低 14.5% 是实的。把预报向训练期均值收缩（β* = 0.9 / 0.7 / 0.9 / 0.8）后量级不变。
  • 二元分类预警（未来 7 天是否成灾）AUC = 0.495，等于随机；已弃用，结果照常披露。
  • 按 NOAA 标准 MMM+1 °C 算出的本站 DHW 恒为 0，原因是基线（短记录暖月均 30.517 °C 对官方长期 MMM 29.4999 °C），不是海温偏暖：本站日均海温与官方「Sabah, Malaysia」区域站点热斑 SST 只差 0.013 °C（r = 0.717）；官方同一站点 2026-10-14 的 DHW = 14.01、Alert Level 2。
  • 跨站点 12 个格（3 站 × 4 时效）现在全部高于持续预报；上一版仙本那 14 天的落败格（0.540 对 0.578）在加入当日原始变量水平后已翻过来，但优势只有 -0.004，不能当成稳赢。
  • 预报区间按模型样本外残差标定（经验 80%），数值天气预报驱动自身的误差未单独传播。
  • 模型输入严格因果（只用当天及以前）：静水位改为「过去 25 天」均值、增水改用 surge_trail；居中口径的静水位 / 增水 / 危险指数只作事后分析量，不喂模型。用 6 个截断点、只用前缀的原始输入重建全部 66 个特征，与全记录逐列比对的最大绝对偏差 0；被排除的居中分析列在最后 8 天里有 7 天无法用过去数据复现（最大偏差 0.0114）—— 这正是它们不能进模型的直接证据。

数据与模型说明（含局限，完整披露） 1. 数据：海温 / 波高 / 潮位来自 Open-Meteo Marine 逐小时再分析，气象来自 ERA5 存档，覆盖 1446 天；官方对照来自 NOAA Coral Reef Watch 5 km v3.1 公开汇总 CSV（1985 年至今）与珊瑚大三角区域灾害等级图。官方 NetCDF 点位序列在本环境不可得（ERDDAP 数据通路重定向到不可达主机，且本机无 HDF5 读取库），改用官方汇总与区域图做交叉印证。 2. 阈值：全部由本站记录期自身分位数确定（浪 p90 = 0.4 m / 雨 p90 = 15.6 mm / 增水 p90 = 0.033 m），不搬用其他海区的固定阈值。 3. 热压力：以本站记录内最暖一个月（2023-05，MMM = 30.517 °C）为基线，按 NOAA 标准 MMM+1 °C 算出的本站 DHW 恒为 0，因此不能据此判断无白化风险。原因是基线取法，不是海温偏暖：官方长期 MMM = 29.4999 °C，而本站只有 3 年多记录；把本站日均海温与官方「Sabah, Malaysia」区域站点逐日比对，两者只差 -0.013 °C（r = 0.717）。官方同一区域站点最新 DHW = 14.01、预警级别 4（4 = Alert Level 2，最高档）——绝对口径在报警，本页指数是相对本站自身历史的量。 3b. 预报口径：未来 8 天由数值天气预报驱动——浪高、海温、水位取自 Open-Meteo 海洋预报，降水取自其气象预报；把这些预报值按与历史完全相同的定义拼进驱动序列后，重算滚动特征、逐日复合灾害判定与记忆特征，再交给模型预测，因此每天的指数都随预报变化，不再是一条水平线。受海浪 / 海温预报产品时效限制，驱动预报只能覆盖到 8 天，更远的时效不作数。区间宽度按样本外残差的经验分位数标定，不是拍脑袋：同一批残差里 ±1×RMSE 的实际覆盖率是 69.5% 到 76.0%（高斯名义值 68.3%），要覆盖 80% 需要的倍数是 1.18 到 1.28 倍 RMSE，页面画的就是这个 80% 经验区间。预报驱动本身的误差未单独传播，所以真实风险仍可能落在区间之外。 4. 模型：岭回归（66 个特征 = 滚动 / 记忆 / 季节特征 + 当日原始变量水平），收缩强度 λ 由训练窗内部交叉验证逐折挑选（不接触测试段）。表中全部为样本外数值，四个时效的 RMSE 都低于常数均值基线（永远预报训练期平均值）：1 天 0.1406 对 0.1644、3 天 0.1603 对 0.1637、7 天 0.1624 对 0.1635、14 天 0.1615 对 0.1638。但必须说清量级：3 / 7 / 14 天的优势只有 0.0035 / 0.0011 / 0.0024，属噪声量级；只有 1 天的 14.5% 是实的。这个指数有 72.8% 的日取值为 0，RMSE 被多数类主导、对"永远报平均"的常数预报最有利，因此我们把排序指标与 RMSE 并列看。 4b. 因此模型的真实价值要换一把尺子衡量——排序能力：把未来第 h 天"至少一项驱动超阈值"的日子排到前面的 AUC，模型为 0.795 / 0.665 / 0.600 / 0.615，高于持续预报 0.587 / 0.429 / 0.433 / 0.583 与气候平均 0.443 / 0.439 / 0.441 / 0.461；模型与实况的相关系数为正（0.515 / 0.249 / 0.130 / 0.178），而持续预报在 3 / 7 天为负（-0.105 / -0.087）。操作者要问的是"哪几天更该小心"，这正是排序指标回答的问题，也是本产品弃用二元分类（样本外 AUC 0.495）、改用连续指数回归的原因。 5. 本页是研究演示，不是官方预警；任何实际停航 / 闭园决策须以马来西亚气象局 (MetMalaysia) 与沙巴公园管理局的发布为准。 6. 分发形态：本页是单文件离线页（全文内嵌、不含任何脚本与外部请求），双击就能打开；部署到公开网址后，地址会自动出现在这句话里。
