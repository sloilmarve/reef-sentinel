## 二、正文（中文，约 1,400 字，整段粘贴）

> **问题**：仙本那（4.6°N, 118.7°E）是全球珊瑚大三角的旅游与修复热点。那里的珊瑚礁不是被单一因素压垮的——海水升温、强降水带来的陆源径流、大浪、风暴增水，这四类压力经常在**同一周内叠加**（指数合成只用浪、雨、增水三类，海水升温单列为热压力指标；但预测因子已包含海温的滚动统计与当日水平）。现有工具的问题是：NOAA 的白化热压力产品是区域级栅格，需要 GIS 背景才能读；而真正要决定「明早船开不开、苗圃收不收、岸线巡不巡」的人拿不到可执行信息。
>
> **我们做了什么**：把 2022-11-01 至 2026-10-16 共 **1,446 天**全公开数据（Open-Meteo Marine 逐小时海洋六变量 + ERA5 逐日气象八变量）做成一条可复现流水线——用 25 天中心滚动均值分离潮汐得到增水残差（居中口径只作事后分析，模型输入改用因果的「过去 25 天」口径），用**本站记录期自身分位数（p90）**定义浪、雨、增水三类超阈值事件（海温单列为热压力），再以「同一天两项及以上超阈值」定义复合灾害日（**44 天，占 3.0%**；把取等号改成严格大于则降为 39 天，这个敏感性也写在材料里）。危险指数是 0–1 连续量，用岭回归（**66 个特征**：滚动统计、灾害记忆、季节项与当日原始变量水平；λ 由每一折训练窗内部的交叉验证挑选；纯 NumPy）做 **1–14 天**预报。
>
> **结果**：扩展窗前推交叉验证下，样本外 RMSE 在 1 / 3 / 7 / 14 天**全部优于**持续预报与气候平均，分别低 **20.8% / 17.2% / 15.4% / 8.9%**。**也要把最不利的一条说清楚**：指数有 72.3% 的日值为 0，"永远预报平均值"的常数均值基线极难被超过——模型在 3 / 7 / 14 天只比它低 0.0035 / 0.0011 / 0.0024（**0.1603 / 0.1624 / 0.1615** 对 0.1637 / 0.1635 / 0.1638），属噪声量级；只有 1 天的优势是实的——相对持续预报低 20.8%（0.1406 对 0.1776）、相对常数均值低 14.5%（0.1406 对 0.1644）；模型的可用价值在**排序**——把"至少一项超阈值"的日子排到前面的 AUC 为 **0.796 / 0.665 / 0.600 / 0.615**，全时效高于持续预报（0.585 / 0.438 / 0.437 / 0.583）。成品是一个**单文件、断网也能打开、禁用 JavaScript 也能读全部数字**的页面（内置的一小段脚本只做导航高亮与折叠增强）：今日风险卡、8 天预报（数值天气预报驱动，区间按各时效样本外残差标定为经验 80%）、与两个基线的对比表、近 180 天与近 300 天历史、年度病历表，以及面向潜店 / 修复队 / 度假村与政府的三档行动建议。
>
> **官方交叉印证**：页面底部内嵌 NOAA Coral Reef Watch 5 km v3.1 的公开汇总（1985-03-25 至 2026-10-13，15,178 天白化预警区计数与占比）与珊瑚大三角区域灾害等级图。官方记录把 **2024 年**列为 1985 年以来最严重年份（全球峰值占比 15.75%、太平洋 20.65%；1985–2000 年全球峰值从未超过 4.76%），而本站从公开数据算出的**复合灾害日最多的年份也正是 2024 年（15 天）**——两条独立来源方向一致（2025 年紧随其后：官方 14.51% 对本站 12 天；两者量纲不同，不构成独立验证）。同海域的区域虚拟站点「Sabah, Malaysia」进一步把对照拉到逐日：本站 13 次热浪 **13 次**（**100.0%**）落在官方预警期内（但该站 82.3% 的日子本就在官方预警状态，提升仅 1.21 倍，这条只能证明无漏报、区分度很低），本站日均海温与官方热斑像素 SST 平均只差 **0.013 °C（r = 0.717）**。
>
> **哪里不行（如实说）**：二元「未来 7 天是否成灾」分类器的样本外 **AUC 只有 0.495（≈随机）**，且 3 天以上的分类表现不如朴素持续预报——因为复合灾害成簇出现，强自相关让朴素预报很难被超越。所以产品**弃用了「未来 7 天是否成灾」这个二元分类器**，只保留连续指数回归，并在页面上写明「指数是统计估计，不替代现场判断」（白化那一路仍在用「未来 28 天出现热浪日」的二元概率模型，见成品页的学习模型卡）。NOAA 的 5 km 单点 NetCDF 序列在我们运行的环境里取不到（元数据可读、数据通路不通），取数命令已留档并写进材料。**新加的一层**：白化预警已从规则升级为学习组件——预测未来 28 天是否出现热浪日，4 折扩展窗池化 PR-AUC **0.364**，高于现行规则 0.311 与基准发生率 0.242（ROC-AUC 0.706），分折反例（第 3 折规则 1.000 而模型 0.499）照常保留。
>
> **怎么看**：下载压缩包，双击 `demo/index.html` 即可（无需联网、无需安装）。想自己刷新数据就双击 `更新数据.bat`，本机实测 37 秒到 143 秒跑完取数 → 指标 → 模型 → 未来驱动预报 → 重画（纯 NumPy，零费用、零服务器；换一个新站点只需在 `pipeline/fetch_multisite.py` 的 `SITES` 里加一行坐标）。
>
> **求反馈**：欢迎任何来自潜水/修复/海岸管理一线的意见——尤其是「这个指数在你的场景里够不够用、缺哪个变量」。团队成员：〔姓名〕（〔团队名〕）。

## 三、英文短版（国际评委 / 英文社区用）

> **Reef Sentinel** turns 1,446 days of fully public data (Open-Meteo Marine hourly + ERA5 daily) into a single 0–1 compound-hazard index for the coral reefs of Semporna, Sabah, and forecasts it 1–14 days ahead with a pure-NumPy ridge regression. A 66-feature ridge regression (rolling statistics, hazard memory, seasonality and same-day raw levels; the shrinkage λ is chosen by inner cross-validation inside each training window only) beats both persistence and climatology at every lead time we report (20.8% / 17.2% / 15.4% / 8.9% lower at 1 / 3 / 7 / 14 days), and its ranking AUC (0.796 / 0.665 / 0.600 / 0.615) stays above persistence everywhere — although at 3 / 7 / 14 days the RMSE edge over the constant-mean baseline is only 0.0011–0.0035, i.e. noise level, which we state openly. The deliverable is one offline HTML file that needs no JavaScript to read (one small inline script only adds navigation and progressive disclosure): today's risk card, an 8-day forecast with an empirical 80% interval, baseline comparisons, and role-specific actions for dive operators, restoration teams and local government. We also disclose what failed: a binary "outbreak within 7 days" classifier scored AUC 0.495 and was dropped. NOAA CRW 5 km aggregate statistics and the Coral Triangle hazard maps are embedded for cross-validation — the official record and our own both rank 2024 as the worst year since 1985.

### 8.3 LinkedIn（英文，专业语气，约 150 词）

Semporna, Sabah sits in the Coral Triangle: a dive-tourism economy and a restoration programme on the same reef system. The operational question there is not "what is the bleaching risk this season" — it is "can we take the boat out tomorrow, and should the nursery crew dive this week".

Reef Sentinel answers it with one number. We turn 1,446 days of public data into a compound-hazard index over three drivers (wave, rain, storm surge) above the station's own record-period p90, forecast 1–14 days ahead by a 66-feature ridge regression trained and validated within expanding windows, and publish the result as a single offline HTML file that refreshes itself daily.

We also publish what did not work: a binary outbreak classifier (AUC 0.495) was dropped, and at 3 days and beyond the margin over a constant-mean baseline is within noise. The 2024 ranking matches NOAA Coral Reef Watch's official record.

Code and materials: github.com/sloilmarve/reef-sentinel
